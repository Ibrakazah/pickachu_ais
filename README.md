# Aqbobek Lyceum School Portal (Expanded Edition)

Unified digital environment for student success, predictive analysis, and smart scheduling.

## 🚀 Key Features

*   **👨‍🎓 Student Dashboard**: Real-time grades integrated with BilimClass, AI-Tutor with predictive analytics, skill tree, and achievements.
*   **👨‍🏫 Teacher Panel**: Early Warning System (EWS) to detect performance drops, AI Class Report generator.
*   **🛡 Admin Dashboard**: Global education radar, automated constraint-based Smart Schedule generator.
*   **👨‍👩‍👦 Parent Mode**: Observer view with Weekly AI summaries and recommendations.
*   **📺 Kiosk Mode**: Interactive hall panel with auto-scroll news, daily leaderboard, and live schedule updates.
*   **🃏 Gamification**: Dynamic leaderboard, points (XP), and unlockable achievements.
